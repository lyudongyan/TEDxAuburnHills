# TEDxAuburnHills project

The project root is organized by purpose:

- `website/`: the static website deployed to GitHub Pages
- `source-assets/`: original organizer-supplied portraits, backgrounds, QR codes, and reference files
- `poster-build/`: poster generation and quality-assurance files
- `poster-output/`: finished poster deliverables
- `tools/`: website validation and project utilities
- `.github/`: GitHub Pages deployment workflow

Only `website/` is published. Keep original files in `source-assets/` and copy web-ready versions into `website/assets/` when the site needs them.
